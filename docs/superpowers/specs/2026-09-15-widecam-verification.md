# WideCam 검증 결과

- 대상: `feature/widecam-v1`, 최종 코드 HEAD `4c92793`
- 검증 일자: 2026-09-15 ~ 2026-09-16
- 검증 방식: 단위 테스트(자동) + 실기기 수동 스모크 5라운드 + 배포 번들 검증. 실기기 실행은 매 회 사용자 승인 하에 수행했다.

## 자동 검증

- 단위 테스트 8종(포맷 정책 6, 저장 경로 2) 전부 통과. 실행은 `./scripts/test.sh`로 한다 — Command Line Tools 환경에서 순수 `swift test`는 Swift Testing 매크로 플러그인 탐색이 간헐적으로 실패하므로, 래퍼가 플러그인 경로를 `xcode-select -p`로 유도해 고정한다.
- 릴리스 빌드(`swift build -c release`) 클린. 링커 검색 경로 경고 2건은 bare CLT 환경 산물로 코드와 무관하다.

## 실기기 스모크 결과

아이폰 기종은 iPhone18,1, macOS 27.0에서 검증했다.

### 통과 항목

1. **최대 화각 강제**: 아이폰 연속성 카메라가 1920×1440(4:3)로 표시되고, Photo Booth 대비 넓은 화각을 유지한다. 이 앱의 존재 이유가 실기기에서 확인됐다.
2. **센터 스테이지 강제 해제**: 제어 센터에서 센터 스테이지를 켠 상태로 앱을 시작해도 화각이 넓게 유지되고, 상태 배지가 "센터 스테이지 해제됨"으로 표시된다. 재강제 루프가 CPU를 태우지 않는다.
3. **사진 촬영**: HEIC(실제 컨테이너, `public.heic`) 1920×1440으로 저장된다. 같은 초에 두 장을 찍으면 `_2` 접미사로 충돌 없이 둘 다 남는다.
4. **영상 녹화**: .mov(HEVC) 1920×1440으로 저장되고, 아이폰 마이크 소리(AAC 1채널)가 담긴다. 마이크를 녹화 시점에만 연결하도록 바꾼 뒤에도 HEVC 코덱과 오디오 트랙이 정상이다.
5. **마이크 점유 시점**: 프리뷰만 켠 동안에는 마이크가 붙지 않아 메뉴바 마이크 표시등이 뜨지 않고, 녹화하는 동안에만 표시등이 켜진다. 사용 설명 문구("영상 녹화에")와 실제 동작이 일치한다.
6. **첫 녹화 마이크 권한 경로**: 마이크 권한을 초기화한 서명 번들에서, 첫 녹화 시 권한 프롬프트가 뜨고 허용하면 녹화가 실제로 시작된다. 권한 대화상자가 팝오버를 닫아도 세션이 유지되도록 한 수정(`isRecordingStartPending`)이 실기기에서 확인됐다.
7. **전체화면 자동 숨김**: 전체화면에서 2.5초 무활동 시 툴바·상태 표시·커서가 사라지고, 마우스 움직임으로 복귀한다. 녹화 중과 센터 스테이지 해제 실패 표시는 숨지 않는다.
8. **메뉴바 상주**: 배포 번들이 Dock에 뜨지 않고 메뉴바에만 상주한다(`LSUIElement`). 앱 아이콘이 정상 표시된다.
9. **유휴 자원**: 앱 실행 직후 팝오버를 열기 전 유휴 CPU 0.0%. 발화하는 타이머·폴링이 없다.

### 배포 번들 검증

- 코드 서명이 Apple Development 인증서 정품 체인(WWDR → Apple Root)으로 유효하다.
- 재배포(리빌드 + 재서명) 후 앱을 다시 실행해도 카메라·마이크 권한을 다시 묻지 않는다. 번들의 cdhash는 바뀌지만 서명 신원이 동일해 TCC 권한 레코드가 유지된다. ad-hoc 서명을 금지한 설계 결정(빌드마다 권한 초기화 방지)이 실기기에서 확인됐다.

## 스모크가 잡은 회귀

수동 스모크가 정적 리뷰로는 잡히지 않은 결함 둘을 실기기에서 적발했다.

1. **프리뷰 세션 부착 경합 크래시**: 메뉴바 구조로 프리뷰 표면이 둘이 되면서, 프리뷰 레이어의 세션 부착(메인 스레드)이 `startRunning()`의 연결 순회(sessionQueue)와 겹쳐 "Collection was mutated while being enumerated" 예외로 앱이 종료됐다. 프리뷰 부착·해제를 sessionQueue로 직렬화하고, 뷰가 세션을 직접 쥐는 길을 컴파일 차원에서 막아 재발을 방지했다.
2. **기기 발견 전파괴**: 성능 감사가 "죽은 값"으로 판정한 `.external` 기기 타입을 제거했더니 아이폰이 목록에서 사라졌다. 이 macOS에서 아이폰 연속성 카메라는 `.continuityCamera`가 아니라 `.external` 타입으로 열거되고 `isContinuityCamera` 필터가 선별을 담당한다는 것이 스파이크 실측 기록에 이미 있었다. `.external`을 복원하고 실측 사실을 주석에 박아 재제거를 막았다.

## 남은 백로그 (v1.1 후보, 공개 전 필수 아님)

- 영상 저장 경로의 심볼릭 링크 리다이렉트 방어(사진 경로는 `.withoutOverwriting`으로 처리됨).
- `isRecordingStartPending`을 불리언이 아닌 참조 카운트로 바꿔 연속 녹화의 미세 창 제거.
- 세션 도중 제어 센터로 센터 스테이지를 다시 켤 때 `forceCenterStageOff` 재호출(현재는 포맷만 재강제하므로 화각은 유지되나 제어권 재설정은 생략된다).
- 미러 상태를 sessionQueue 단일 큐로 완전히 통일.
